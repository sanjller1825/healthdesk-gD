# MedicApp — Gestión de Pacientes (React + Vite + Tailwind)

## Requisitos
- Node.js 18+ y npm

## Instalación
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Tecnologías
- React 18, React Router
- TailwindCSS
- Zustand (estado persistente en localStorage)
- dayjs
